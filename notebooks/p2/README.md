# Análisis P2 — Vía B

Directorio reservado para auditoría M5, formulación, comparación de algoritmos y ablaciones. Los notebooks de P1 permanecen en el directorio padre.

Iniciar el entorno desde la raíz del repositorio con `bash docker/setup_p2.sh`. Jupyter se publica sólo en localhost, por defecto en el puerto 8889, y conserva autenticación por token. Los resultados retail irán en `../artifacts/p2_via_b/`.

El setup prueba dependencias usando CartPole; no es un experimento M5 ni una implementación de los tres agentes.
